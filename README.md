# Portal ARCOP

Sistema de gestión de solicitudes de acceso a datos personales según Ley 21.719 de Chile.

## 🚀 Demo

[Ver demo en vivo](https://tu-url.vercel.app)

## 🔧 Tecnologías

- React 18.3.1
- React Router DOM 6.30.3 (HashRouter)
- Google Apps Script (Backend)
- Google Sheets (Base de datos)
- Gmail API (Notificaciones)
- Vercel (Hosting)

## 📦 Desarrollo local

\`\`\`bash
# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env
# Editar .env con tus valores

# Iniciar servidor de desarrollo
npm start
\`\`\`

## 🌐 Variables de entorno

Ver \`.env.example\` para las variables necesarias.
